- **Hero 背景**: Unsplash の「office / japan / calm / business」系画像

- **About 挨拶セクション**: オフィス内観風の Unsplash 画像
  - 例: `https://images.unsplash.com/photo-1497366216548-37526070297c?w=1200&q=80`
- **Services アイコン**: インライン SVG（3カード揃え） — 出自問わず統一
- **Philosophy 装飾**: CSS グラデーション + 大きな引用符 SVG
- **TKC バッジ**: テキスト＋CSS装飾のみ（画像なし）
- **OfficeInfo**: 画像なし、テーブルのみ

## テキスト省略・移動

- TKCシステム詳細（FX4クラウド等）のサブページテキスト: デモでは使用しない
- 補助金・融資情報の長文: デモでは使用しない
- reCAPTCHA プライバシーポップアップ文: デモでは使用しない
- セミナー2017 など古い情報: 使用しない
- 経営改善オンデマンド講座のストーリー: 使用しない

すべて「メインページを現代的にリデザイン」する範囲に絞る。サブページは別ページリンク扱いで省略。
