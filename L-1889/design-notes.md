## リデザイン方針

1. **Hero を作り直す**: 元サイトの派手な告知バナーを排除し、静かで大きな余白のヒーロー。
   - Headline: 「**信託制度を活用して個々に合わせたオーダーメイドの支援を**」（/access/tsukuba/ の原文）
   - Sub: 「**TSUKUBA OFFICE**」
   - Body: /access/tsukuba/ の本文冒頭（原文そのまま）
   - 左テキスト / 右 Unsplash 画像（つくば研究支援センター相当 = オフィスビル or 研究的な都市写真）、CTA = TEL + お問い合わせ

2. **つくばに最適化**: ヘッダー電話番号は **029-846-6444**（つくば事務所）を主表示にする（leads.json と一致）。ちば事務所は Footer の 2 拠点表示で残す。

3. **告知・セミナー情報は採用しない**: 2022 年で停止している古い情報のため、時系列リスクが大きい。ただし「一般社団法人相続手続支援機構」インタビュー等、時期に依存しない権威情報は採用。

4. **情報アーキテクチャ**:
   - Header（Nav: 当事務所について / 業務内容 / 相続 / 農業経営 / 社会福祉法人 / アクセス / お問い合わせ）
   - Hero（つくば事務所）
   - Intro（お客様のお悩みにオーダーメイド / 事務所の特長）
   - Philosophy（経営理念 + 代表メッセージ + 逆井甚一郎代表写真）
   - Services（相続 / 農業経営 / 社会福祉法人 / 確定申告 / 事業承継）
   - About（当事務所について：中立的な税理士 / 約 50 年の実績）
   - Access（つくば事務所情報 = メイン + ちば事務所 = 補助）
   - Affiliations（所属・協力機関）
   - CTA / Contact（電話 + フォーム）
   - Footer（2 拠点の住所・電話・FAX、定休日）
