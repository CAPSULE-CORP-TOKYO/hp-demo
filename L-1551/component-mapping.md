# コンポーネント割当表

## サイト構造（単一ページランディング）

1. **Header** — ロゴ（テキスト）+ ナビ + TEL
2. **Hero** — キャッチコピー（私たちの目的）+ 事務所外観写真
3. **Mission** — 川合会計なら（TKC トータルサポート）
4. **About** — 事務所概要・歴史・所員構成
5. **Services** — 経営・税務・会計・労務
6. **Boss** — 所長挨拶 + 顔写真 + プロフィール + 三信条
7. **News** — 更新情報（2020 年コロナ対応）
8. **Access** — 所在地・アクセス・地図
9. **Contact CTA** — 電話・メール
10. **Footer** — Copyright
11. **Mobile Fixed Bar** — TEL + Contact

### 省略・差替の判断

| 元テキスト | 扱い | 理由 |
|---|---|---|
| 事務所行事ページの 2011-2012 年セミナー詳細（event.html 全文） | 省略 | 10年以上前のイベントを掲載すると逆に信頼性を損ねる。元サイトの「更新情報」も 2020年が最新のため、News には 2020 年コロナ対応 6件のみ掲載。 |
| 朋友会発足等の組織内イベント詳細 | Boss/About タイムラインに年次のみ記載 | テキスト自体は About タイムラインで継承 |
| TKC プログラム・お役立ちコーナー等の外部バナー | Mission セクション内のテキストリンクに統合 | 元がテキスト焼込画像のため、テキストで再現 |
| 「ウェブページ開設」昭和表記等 | About タイムラインでそのまま継承 | |

**全テキストの主要情報は網羅。古いセミナー詳細のみ省略（デザイン上の判断）。**

### マッピングルール遵守
- 同一セクション内で並列するカード（Services の経営/税務/会計/労務）は画像を使わず、全て SVG アイコン + テキストに統一。混在なし。
- 人物写真は所長 1 名のみ（Boss セクション）。切れない丸型トリミング。
- Hero には事務所外観写真をサブ画像として配置（切れない縦長トリミング）。
