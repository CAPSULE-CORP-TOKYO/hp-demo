あなたはエキスパートのフロントエンド開発者です。3つの入力を提供します:

1. 元サイトのスクリーンショット（正確なテキスト内容のソース）
2. リデザイン画像（視覚的デザインの方向性）— このデザインをできる限り忠実にHTML/CSSで再現すること
3. テキストインベントリ（原文テキスト — 一字一句そのまま使うこと）
4. 画像マッピング表（元サイトの画像URL — 指定された画像は必ず使うこと）

・AIが文章を創作・要約・言い換えすることは厳禁
・画像は画像マッピング表の指定に従え。「Unsplash差替」指定の箇所はUnsplashの高品質画像を使え

━━ 技術要件 ━━
- 単一HTMLファイル（インラインCSS + 最小限のJS: ハンバーガーメニューのトグルのみ）
- Google Fonts: Noto Sans JP (400, 500, 700)
- 完全レスポンシブ: 375px〜1440px、Mobile-first
- ブレークポイント: 768px, 1024px
- tel:リンク付き電話番号
- CSS transitions/hover effects
- 写真は画像マッピング表に従う。全て Unsplash（https://images.unsplash.com/ からビジネス/オフィス系）を使用
- セマンティックHTML5
- ナビゲーション: デスクトップでは横並び、モバイル（768px以下）ではハンバーガーメニュー（JSトグル）
- モバイル追従CTAバー（768px以下で画面下部固定、TEL+問い合わせボタン）
- **余白ルール（全画面サイズ共通）:** 全てのセクション・カード・画像・コンポーネントは、画面端に直接接触してはならない。コンテンツ領域は max-width + margin: 0 auto で中央配置し、左右に十分な余白を確保すること。モバイルでは最低 padding-inline: 16px。コンポーネントが viewport 幅いっぱいに張り付くレイアウトは禁止
- **小さいアイコン画像の扱い:** CSS/SVG アイコン、Unicode シンボル、または Font Awesome 等で代替すること

HTMLコードのみ出力。マークダウンや説明は不要。
