# コンポーネント割当表

## サイト構造

1. **Header** — 事務所名ロゴ + グローバルナビ（デスクトップ横並び / モバイルハンバーガー）+ TEL
2. **Hero** — キャッチ + メインメッセージ + CTA
3. **Concept** — 経営理念・誠実さ
4. **About/代表挨拶** — 代表の言葉と人物像
5. **Services** — サービス概要（会計業務・税務業務・税理士変更・法人設立）
6. **税理士変更** — 解決できる不満 + 変更の流れ
7. **開業/法人設立Q&A** — Q1〜Q6 / A1〜A6
8. **事務所概要** — 基本情報 + 営業エリア
9. **ご相談の流れ** — 4ステップ（CSS 再構築）
10. **Contact** — 連絡先 + 地図リンク
11. **Footer** — コピーライト + 最小ナビ
12. **Mobile CTA Bar** — 固定 TEL + コンタクトボタン（768px 以下）
