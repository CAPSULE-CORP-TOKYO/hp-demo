名前: **A: モダンミニマル**（副次的に E: テキストヘビーの要素を吸収）

### 画像方針のまとめ

- ヒーローは **Unsplash のモダンなオフィス/ビジネス写真**（office-interior / business-meeting）で置く。モダンミニマルなので高品質な 1 枚だけで十分。
- 「業務内容」のカードは **CSS/SVG アイコン**で統一（6つの業務 × 線画アイコン）。写真の枚数が揃わないため。
- 「事務所紹介」セクションに **事務所外観写真（引き継ぎ #69）** を使う。固有の価値がある唯一の写真。
- スタッフ写真は使わない（ストック素材しかないので代わりに体制を数字で見せる）。
- ロゴは HTML テキスト（Noto Serif JP）＋ 金のアンダーラインで表現。

## 差別化方針（diagnosis 反映）

diagnosis で指摘された問題:
1. デザインが古く 2010年代前半の印象 → モダンミニマル・大胆な余白
2. バナーやサイドバー要素が多くゴチャゴチャ → 単一カラム、ミニマルなナビ
3. 元 URL が http:// → https 前提で構築
4. 写真・イラストの品質が低い → 1 枚の高品質 Unsplash + 固有の事務所外観写真のみ、他は SVG
