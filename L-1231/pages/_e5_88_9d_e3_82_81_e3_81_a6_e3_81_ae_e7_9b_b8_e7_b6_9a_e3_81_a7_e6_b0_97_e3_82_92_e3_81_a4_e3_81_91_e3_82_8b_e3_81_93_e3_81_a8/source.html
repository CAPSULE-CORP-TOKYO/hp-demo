経営・税務のお役立ち豆知識

初めての相続で気をつけること

投稿日：2024年11月7日

「初めまして。父が亡くなり相続の手続きを進めているところです。私も財産を相続することになりました。 相続の手続きについて全く分かりません。教えていただければと思いまして・・・。」

「初めまして。ご相談頂きまして、ありがとうございます。お父様の相続についてのお悩みですね。初めての方には、少し複雑に考えられることも多いと思います。分かりやすくご案内しますね。 先ずは相続税の申告が必要かどうかを一緒に考えていきましょう。」

「ありがとうございます。どのような点を確認すればよいでしょうか？」

 

目次[表示]

相続税の申告は必要か？判断するには？？

「相続税の申告・納税が必要かどうかは【相続税の基礎控除】から判断します。相続税の基礎控除は、【3000万円＋600万円×法定相続人の人数】で計算できます。つまり、遺産総額がこの基礎控除額以下であれば相続税の申告は不要です。ちなみに法定相続人というのは、配偶者やお子様など、法律で定められた相続権を持つ方々のことです。お父様の法定相続人はどなたになりますか？」

「父には妻（私の母）と私を含めた子供が２人います。母、私、弟が相続人ですね。」

「そうですと、法定相続人の人数は３人ですね。この場合、基礎控除額は【3000万円＋600万円×３人】となり4800万円となります。つまり、お父様の遺産総額が4800万円以下であれば、申告は不要です。」

「なるほど！ですが、遺産の総額がそれを超えていそうなのです。申告が必要になる場合、どのような流れで進めればよいでしょうか？」

「かしこまりました。相続税の申告が必要な場合、以下の流れで進めていきます。」

 

相続税申告までの流れ

１．財産の把握
先ずは、お父様の財産を全てリストアップしていきます。例えば、不動産や預貯金、有価証券、生命保険、貸付金などが該当します。

２．債務や葬儀費用の把握
お父様に借金があった場合や、葬儀にかかった費用も相続財産から差し引くことができます。


３．評価額の算定
財産の総額がわかったら、各財産の評価額を算出します。例えば、不動産であれば路線価や固定資産税評価額を使って評価を行います。


４．相続税額の計算
財産から債務を差し引いた正味の遺産額に基づいて相続税額を計算します。


５．申告書の提出
相続税の申告書を提出し、相続の開始があったことを知った日の翌日から10か月以内に税務署へ提出します。

「なるほど。思っていたよりも色々と確認する必要があるのですね。特に不動産の評価額などは自分では難しそうです。」

「そうですね、財産の評価は専門的な知識が必要なので、なかなか大変ですよね。特に不動産については仙台の地価はここ数年で結構アップしているので、思っていたよりも高い（相続税が多くなる）ケースがあり、驚かれることも多々ございます。他にも、生命保険や退職金などで一定の非課税枠が設けられている財産もありますので、これらを計算に入れて負担が減るように調整することも大事です。」

「非課税枠もあるんですね。それであれば、少し安心です。」

「そうですね。加えて、配偶者であるお母様が取得する相続分についても「配偶者の税額軽減」という特例があります。これにより、配偶者が取得する財産に対する相続税が大幅に軽減される場合が多いです。

「母が相続する分は相続税が軽減されるんですね！それなら私たちの負担も少なくなるかもしれませんね。どのくらいの財産を相続する場合に特例が適用されるのでしょうか？」

「配偶者が相続する財産には、1億6000万円までの相続税がかからないという特例と、配偶者が法定相続分を超えない範囲で相続する場合に無税になる特例があります。このどちらか大きい方が適用されます。状況に応じて軽減を受けられる可能性が高いです。」

「なるほど！そういう特例を上手く使っていけば負担が少なくなりそうですね。でも、全体を整理していくのがたいへんそうですね・・・。」

「そうですね、相続税の申告は専門的な知識が必要なことも多く、手続きも複雑です。申告内容に誤りがあると後日税務署から指摘を受けて追加の税金が発生することもあります。最初にしっかりと手続きされることをお勧めします。」

 

当社では、宮城県及び近隣各県の皆様より多数ご相談いただいております。是非ご相談ください。
